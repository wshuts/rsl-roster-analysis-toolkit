# RSL Roster Analysis Toolkit Project Brief

## Current State

RSL Roster Analysis Toolkit is in the idea-capture and project-shaping stage.
The repository contains a lightweight Python-oriented scaffold, but that should
be treated as a starting workspace rather than a final technology decision.

## Working Premise

The project should make it easier to analyze a Raid: Shadow Legends roster and
find champions with specific skillsets, roles, or build potential. The workspace
can preserve ideas from prior ChatGPT conversations while the product shape and
technical direction are still being clarified.

## Open Questions

- What is the primary user workflow?
- What roster, champion, artifact, blessing, mastery, or team data will the
  project ingest or organize?
- Does the project need a CLI, a web app, a notebook-style analysis workflow, or
  a service/API?
- Is Python still the best fit, or should the core be built with another stack?
- What ideas from prior ChatGPT conversations should be preserved here first?

## Near-Term Workspace Goals

- Capture the important product ideas before overcommitting to implementation.
- Keep the repository structure easy to change.
- Add small, testable prototypes only after the first workflow is clear.
